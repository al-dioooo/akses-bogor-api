# AksesBogor API

API untuk AksesBogor, aplikasi informasi aksesibilitas fasilitas publik di Kota Bogor. Dibangun dengan Fastify (TypeScript) dan Neon Postgres + PostGIS, lalu di-deploy ke Azure App Service ([ADR-0013](https://github.com/al-dioooo/akses-bogor-docs/blob/main/decisions/0013-tech-stack-nextjs-fastify.md)).

Repo ini sedang disiapkan. Petunjuk menjalankan, environment variables, dan deployment ditambahkan bersama kerangka proyek.

Keputusan produk dan teknis ada di [akses-bogor-docs](https://github.com/al-dioooo/akses-bogor-docs). Aturan kontribusi ada di [AGENTS.md](AGENTS.md).
